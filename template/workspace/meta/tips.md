# tips

Queue of suggestions for the system itself: a tip, a video, a tool, "you should also do X" from a colleague, a post. Nothing here changes the system until Friday's `review` runs `improve` on it and the user says yes.

Format: `- [ ] YYYY-MM-DD · <tip in one line> · from: <who or where> · link: <url>`
Done: `- [x] ... · verdict: adopt | backlog | discard (YYYY-MM-DD)`
